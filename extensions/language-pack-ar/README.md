# حزمة اللغة العربيّة (مدمجة) — `language-pack-ar`

حزمة لغة عربيّة **مدمجة (built-in)** تُعرّب واجهة محراب (القوائم، الأوامر، الإعدادات)
إلى العربيّة. مع `defaultLocale: "ar"` في `product.json` (رُقعة `main.ts`)، تكون واجهة
محراب **عربيّة افتراضيًّا** بتهيئة صفريّة.

## المصدر والقيد

- **منسوخة من** `arabic_vscode/lang-pack` (حزمة لغة VS Code العربيّة، `contributes.localizations`
  + `translations/` بصيغة `i18n.json`).
- **قيد إصدار معروف**: الحزمة مبنيّة لـ**VS Code 1.85**، ومحراب على **1.121**. التغطية
  **جزئيّة**: السلاسل المستقرّة (ملفّ/تحرير/قوائم) تُترجَم؛ السلاسل المُستحدَثة في 1.121
  تبقى إنجليزيّة (تراجع آمن). محراب يبني `nls.messages.json` وقت التشغيل من `contents`
  ⇒ متوافق، بلا انهيار. **تحسين لاحق**: إعادة توليد الحزمة لإصدار محراب عبر خطّ ترجمة.
- قد تطبَّق العربيّة بعد أوّل إعادة تحميل (سلوك حزم اللغة في VS Code).

## التعريب آليّة طبقتين

- **الطبقة 1**: هذه الحزمة المدمجة تُتيح العربيّة.
- **الطبقة 3** (رُقعة نواة): `product.defaultLocale = "ar"` يُقرأ في `src/main.ts`
  (`getUserDefinedLocale`) ⇒ العربيّة افتراضيًّا دون ضبط المستخدم.
