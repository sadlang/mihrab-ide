# نِبراس — ذكاء ص في محراب (م2ب)

امتداد يوصّل **نِبراس** (طبقة الذكاء الرسميّة للغة ص) بواجهة محراب عبر عقد
`nebras-protocol` (JSON-RPC 2.0 على stdio) مع خادم نِبراس المقيم.

## المزايا

| الأمر | الوصف | المهمّة | الطبقة |
|---|---|---|---|
| `نِبراس: اشرح التحديد` | يشرح التحديد (أو الملفّ) حيًّا في قناة إخراج عربيّة. | اشرح | متوسّط |
| `نِبراس: افتح الدردشة` | لوحة دردشة RTL عن الملفّ النشط (بثّ حيّ). | اشرح | متوسّط |
| الإكمال السطريّ | اقتراح استمرار الكود أثناء الكتابة (مطفأ افتراضًا). | أكمل | خفيف |
| `نِبراس: أعِد تشغيل الخادم` | يعيد تشغيل خادم نِبراس المقيم. | — | — |

## المعماريّة

```
محراب (هذا الامتداد)
  ├─ extension.js          ← التنشيط + الأوامر + شريط الحالة
  ├─ nebras-process.js     ← خادم نِبراس المقيم (spawn stdio) + مصافحة + إعادة تشغيل
  ├─ rpc-client.js         ← عميل JSON-RPC (تأطير Content-Length، طلب/إشعار/موافقة)
  ├─ permission.js         ← حوار موافقة الأذونات (ق5/ق12)
  ├─ explain-selection.js  ← الميزة 1
  ├─ chat.js               ← الميزة 2 (webview RTL، CSP صارم)
  └─ inline-completion.js  ← الميزة 3 (مبوَّبة بقدرة الخادم «أكمل»)
        │  stdio (Content-Length)
        ▼
  nebras خادم --نقل stdio  ← عقل نِبراس (@nebras/core)
        │  NEBRAS_PROXY_URL
        ▼
  nebras-proxy → Claude    ← المفاتيح والاستحقاق هنا (ق3)، فارغ ⇒ مزوّد وهميّ
```

## الخادم المدمج (التغليف)

يُطلق الامتداد خادم نِبراس من أوّل مسار متاح: `mihrab.nebras.serverPath` ⟵ الخادم المدمج
`server/index.js` ⟵ متغيّر البيئة `NEBRAS_CLI`. الخادم المدمج **أثر مولَّد** (مُتجاهَل في git):

```bash
# في مستودع نِبراس (بعد بنائه):
npm run bundle:mihrab        # ⇐ extensions/mihrab-nebras/server/index.js (ملفّ Node واحد ~250KB)
```

بناء منتج محراب يُنتِج هذا الملفّ فيعمل الامتداد دون تثبيت نِبراس. للتطوير: اضبط `serverPath`
إلى `packages/cli/dist/index.js` أو صدّر `NEBRAS_CLI`.

## الإعداد

| المفتاح | الافتراض | الوصف |
|---|---|---|
| `mihrab.nebras.serverPath` | (مدمج/بيئة) | مسار `packages/cli/dist/index.js`. |
| `mihrab.nebras.nodePath` | `node` | مُفسِّر Node لتشغيل الخادم. |
| `mihrab.nebras.proxyUrl` | (فارغ) | `NEBRAS_PROXY_URL`؛ فارغ ⇒ مزوّد وهميّ (بلا سحابة). |
| `mihrab.nebras.permissionMode` | `آمن` | اقتراح/آمن/طيّار (ق5/ق12). |
| `mihrab.nebras.locale` | `ar` | لغة التفاعل (ق7). |
| `mihrab.nebras.inlineCompletion` | `false` | تفعيل الإكمال السطريّ. |

## طور المحادثة و FIM

- **الدردشة متعدّدة الأدوار**: العميل يحمل تاريخ المحادثة ويمرّره مع كلّ مهمّة (الخادم عديم الحالة ⇒ يصمد عبر إعادة الاتّصال بلا تسريب). يُصفَّر عند إغلاق اللوحة.
- **الإكمال بملء الفراغ (FIM)**: يرسل البادئة (قبل المؤشّر) واللاحقة (بعده)؛ الخادم يملأ الفراغ بينهما بدل إكمالٍ من البادئة وحدها.
- **فرق المصدر (توكنز الدردشة الطويلة)**: للملفّات الكبيرة (> 2000 حرف) يُرسَل المصدر كاملًا أوّل دور، ثمّ **الفرق التدرّجيّ** (مقابل ما رآه النموذج فعلًا عبر `sourceEcho`) في الأدوار التالية — مع تراجع تلقائيّ للمصدر الكامل إن كبر الفرق. الملفّات الصغيرة تُرسَل كاملةً دائمًا (تأريض رخيص). مقايضة موثَّقة: في الأدوار التالية يعتمد النموذج المحادثةَ السابقة + الفرق لا الملفّ الكامل.

## حدود معلومة

- **لا مفاتيح في الامتداد** (ق3/ق6): الخادم يتصل بالوسيط الذي يحملها. لا خروج شبكيّ إلّا عبره.
- الإكمال السطريّ يتطلّب ملفًّا محفوظًا (جسرا السياق يقرآن من القرص).
