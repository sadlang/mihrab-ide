# عقد سلك نِبراس — مصدر حقيقة محراب

مصدر حقيقة واحد يملكه محراب لثوابت عقد السلك التي «تعكس `@nebras/protocol`». الامتداد
CommonJS خارج شجرة بناء TypeScript فلا يستورد الحزمة؛ فبدل إعادة إعلان القيم يدويًّا في
كلّ ملفّ (خطر تباعد صامت)، تُولَّد وحدة واحدة منه ويحرسها فحص آليّ.

## الملفّات

| الملفّ | الدور |
|--------|-------|
| `protocol-contract.yaml` | **المصدر** — حرِّره وحده. مجموعات قابلة للتوسّع (بروتوكول/طرائق/jsonrpc/تأطير/مهامّ/أدوار/حصائل/CLI). |
| `gen_contract.py` | المولِّد. `--check` = حارس التطابق (يُشغَّل في `tests/run.sh`). |
| `protocol-contract.generated.js` | **مولَّد** — لا تُحرِّره. وحدة CommonJS مجمَّدة تستهلكها ملفّات الامتداد عبر `require`. |

## السير

```bash
python contract/gen_contract.py          # ولّد/حدّث الوحدة بعد تحرير المصدر
python contract/gen_contract.py --check  # حارس: يفشل إن انحرفت الوحدة عن المصدر
```

أو عبر npm scripts (`extensions/mihrab-nebras/package.json`):
`npm run gen:contract` · `npm run check:contract`.

## التوسّع

- **ثابت جديد:** أضِف سطر `entry` تحت المجموعة المناسبة، ثمّ أعِد التوليد.
- **قِسم جديد:** أضِف `group` جديدة بـ`name`/`doc`/`entries`.
- القيم العربيّة (أصناف المهامّ/الأدوار/الحصائل/وسائط CLI) بيانات عقد لا نصّ واجهة —
  تطابقها الحرفيّ مع خادم نِبراس إلزاميّ، فلا تُترجَم.

## لماذا مصدر يملكه محراب؟

مستودع محراب لا يحوي `@nebras/protocol` (الخادم يُغلَّف مستقلًّا). فامتلاك محراب لمصدره
يجعله مكتفيًا ذاتيًّا: الحارس يمنع **التباعد الداخليّ** بين ملفّات الامتداد، ومطابقة هذا
المصدر لعقد نِبراس الأصل تبقى قرارًا واعيًا عند ترقية النسخة (`PROTOCOL_VERSION`).
