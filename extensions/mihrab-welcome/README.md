# ترحيب محراب (mihrab-welcome)

امتداد **الطبقة 1** (إضافة محزومة، بلا رُقعة نواة) يوفّر تجربة الإعداد الأوّل في محراب:

- **جولة تفاعليّة عربيّة «ابدأ في ٩٠ ثانية»** (`contributes.walkthroughs`) — أربع خطوات RTL: أنشئ مشروعًا → اكتب → شغّل → افهم الأخطاء. تظهر في صفحة الترحيب (Get Started).
- **أمر «محراب: مشروع ص جديد»** (`mihrab.newSadProject`) — ينشئ مجلّدًا فيه `مرحبا.ص` بقالب حيّ مشروح بالعربية، و`اقرأني.md`، ومهمّة تشغيل جاهزة. يعالج الحالة الحديّة (مجلّد موجود) بلطف دون دوس.
- **أمر «محراب: شغّل ملفّ ص الحاليّ»** (`mihrab.runSadFile`) — يشغّل الملفّ عبر `sad-run` في الطرفيّة، ويرشد المستخدم بلطف إن لم تكن الأداة مثبَّتة.

يعالج بنود UX الحرِجة (P0): أ-١ (الترحيب) و أ-٢ (المشروع الجديد).

## البنية

- `package.json` — المانيفست (الأوامر + الجولة + activationEvents).
- `extension.js` — منطق الأمرين (CommonJS، بلا خطوة بناء؛ يُشحن كامتداد مدمج).
- `media/*.md` — محتوى خطوات الجولة (RTL).

كلّ نصّ ظاهر للمستخدم مركزيّ في ثابت `COPY` داخل `extension.js` (نسخة عربيّة-أوّلًا).

معرّفات الأوامر ونداءات النواة المدمجة ومعرّف الامتداد الاحتياطيّ مرفوعة كلّها إلى ثوابت
مسمّاة (`NEW_PROJECT_CMD`/`RUN_FILE_CMD`/`OPEN_FOLDER_CMD`/`OPEN_CMD`/`DEFAULT_EXTENSION_ID`)
— لا سلاسل معرّفات حرفيّة موضعيّة.

## قرار التعريب (i18n)

عناوين الأوامر ووصف خطوات الجولة تُكتب **عربيّةً مباشرةً** في `package.json` بلا
`package.nls.*` ولا مسار `en` — قرار **«عربيّ-أوّلًا»** مقصود يطابق قرار المستودع الموثَّق
(حزمة اللغة `language-pack-ar` تُعرِّب سطح المنبع؛ و`package.nls.ar` يُتجاوَز مع حزمة لغة
نشطة، فالحقن يكون في محتوى الحزمة). إن صار الهدف لاحقًا ثنائيّ اللغة، يُضاف
`package.nls.json` (إنجليزيّ افتراضيّ) + `package.nls.ar.json`، وتُستبدَل العناوين الحرفيّة
بمفاتيح `%key%`. هذا **دَينٌ مؤجَّل واعٍ** لا سهوٌ. (ينطبق ذاته على امتداد `mihrab-nebras`.)
