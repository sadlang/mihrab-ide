# موقع توثيق محراب العربيّ

يُنشَر على GitHub Pages: <https://sadlang.github.io/mihrab-ide/>

## لماذا مولِّدٌ لنا لا قالبٌ جاهز

دعمُ RTL في القوالب الجاهزة (Docsy · Just-the-Docs · Docusaurus) طبقةُ `[dir=rtl]`
مضافةٌ لاحقًا: تغطّي التخطيطَ ولا تغطّي الحالاتِ الحدّيّة — عزلَ bidi حول `Ctrl+Shift+P`،
واتّجاهَ انزلاق الدرج، وتخطيطَ الطباعة على عمودين. وهذه بالضبط الحالاتُ التي بُني
الموقعُ لأجلها. وترقيعُها أطولُ من كتابة ما نملك، وتفرض هويّةً بصريّة تناقض هويّة محراب.

## البناء

```bash
python site/build.py            # → site/public/
python site/build.py --check    # تحقّقٌ بلا كتابة
```

المخرَجُ في `.gitignore`: يُبنى في CI عند كلّ نشر.

## البنية

| المسار | ما فيه |
| --- | --- |
| `content/*.md` | الصفحاتُ المترجَمة، لكلٍّ ترويسةُ front-matter |
| `data/keybindings.json` | مصدرُ صفحة الاختصارات |
| `data/glossary.json` | المسرد — مصدرُ الحقيقة للمصطلحات |
| `assets/` | CSS وJS (بلا اعتماديّات) |
| `build.py` | المولِّد |

## الترويسة الإلزاميّة لكلّ صفحة

```yaml
---
description: سطرٌ واحد للفهرسة والبحث.
source_path: docs/editing/codebasics.md    # صفحةُ المنبع (شرطُ النِسبة في CC BY)
translated_at: 2026-08-01
source_sha: "…"                            # بصمةُ ملفّ المنبع وقتَ الترجمة
---
```

`source_sha` تُملأ آليًّا:

```bash
python tests/docs/check_drift.py --seed     # يبذر البصمةَ للصفحات الخالية منها
python tests/docs/check_drift.py            # يقارن بالمنبع ويرفع رايةَ الانجراف
python tests/docs/check_drift.py --offline  # اكتمالُ البيانات فقط، بلا شبكة
```

بلا هذا تموت الترجمةُ صامتةً: تُترجَم مرّةً، ثمّ يتغيّر المنبع، فتبقى **تكذب بثقة**
— وهي حينئذٍ أسوأُ من غيابها.

## تعليمُ Markdown المدعوم

مجموعةٌ فرعيّة مضبوطة: عناوين `##`/`###`، فقرات، قوائم، جداول، كتلُ كودٍ مسيَّجة،
كودٌ سطريّ، روابط، `**عريض**`. وما عداها يُرفَض صراحةً لا يُتجاهَل صامتًا.

وزيادةٌ واحدة خاصّة بنا — **الاختصار**:

```
{{Ctrl+Shift+P}}
```

تُصيَّر حاويةً معزولةً اتّجاهيًّا (`unicode-bidi: isolate`). لا تكتب الاختصارَ نصًّا
عاديًّا داخل جملةٍ عربيّة: خوارزميّةُ bidi تنقل علامةَ `+` أو تعيد ترتيبَ الرموز
المجاورة، فيعرض الموقعُ `Ctrl+Shift+P` خطأً.

## المصطلحات

كلُّ مصطلحٍ من `data/glossary.json`، وفحصُ L0 يمسك البدائلَ الممنوعة. السببُ أنّ
توثيقًا يقول «لوحة الأوامر» وواجهةً تقول «لوحة الأوامر السريعة» **أسوأُ من توثيقٍ
إنجليزيّ**: يُشكِّك المستخدمَ في فهمه هو.

## الخطوط

`assets/fonts/*.woff2` غيرُ مورَّدةٍ بعد. المطلوب — IBM Plex Sans Arabic (SIL OFL)
بوزنَي 400 و600، وIBM Plex Mono بوزن 400، مُقتطَعةً على العربيّة واللاتينيّة:

```
plex-arabic-400.woff2  ·  plex-arabic-600.woff2  ·  plex-mono-400.woff2
```

يولّد `build.py` كتلَ `@font-face` **للموجود فعلًا وحده**، ويطبع تحذيرًا بالباقي.
وهذا مقصود: `@font-face` يشير إلى ملفٍّ غائبٍ لا يفشل بصوت — يُطلق 404 في كلّ فتحةِ
صفحة ثمّ يسقط صامتًا إلى خطٍّ آخر، فيبدو الموقعُ سليمًا وهو يعرض خطًّا لم نصمّم عليه.
