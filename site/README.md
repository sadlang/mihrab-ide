# موقع محراب العربيّ

| | العنوان | مَن ينشر |
| --- | --- | --- |
| **الأصل** | <https://sad-lang.org/mihrab/> | `build/deploy_site.sh` (rsync إلى خادمنا) |
| المرآة | <https://sadlang.github.io/mihrab-ide/> | CI عند كلّ دفعٍ إلى `main` |

الأصلُ على خادمنا لأنّ **الثنائيّات تسكن هناك**: مثبِّتُ محراب يقارب ٣٠٠ ميغابايت،
وGitHub Pages ليس مخزنَ ملفّات. والنطاقُ `sad-lang.org` نطاقُ العائلة نفسِها، فمحرابٌ
يسكن مع لغة ص. وإليه تشير هويّةُ المنتج (`product-overrides/product.json`) و`rel=canonical`
في كلّ صفحة. والمرآةُ تبقى لأنّ المولِّد واحد فلا انجراف، ولأنّها احتياطٌ مجّانيّ.

## البنية على الشبكة

```
/mihrab/              الصفحةُ الأولى — واجهةُ المنتج
/mihrab/download/     التنزيل (يقرأ dl/releases.json الحيّ)
/mihrab/dl/           الثنائيّات + releases.json  ← لا يمسّه النشر
/mihrab/docs/         مركزُ التوثيق
/mihrab/start/        صفحاتُ التوثيق — مساراتُها لم تتغيّر عمدًا
/mihrab/keyboard/     (مخبوزةٌ في product.json وفي نسخٍ مشحونةٍ سلفًا)
```

## النشر

```bash
build/deploy_site.sh                       # الموقع → sad-lang.org/mihrab/
build/publish_release.sh 1.121.05071 \
    win-x64-setup:/c/out/MihrabSetup.exe \
    win-x64-zip:/c/out/Mihrab-win-x64.zip  # ثنائيّات → dl/ + مانيفستٌ حيّ
```

`deploy_site.sh` يستثني `dl/` من `--delete` ويبدّل المجلّدَ ذرّيًّا. و`publish_release.sh`
يحسب SHA-256 **على الخادم بعد الرفع** — البصمةُ تصف ما وصل لا ما غادر.

## مانيفستُ الإصدار — نسختان عمدًا

| | أين | مَن يكتبها |
| --- | --- | --- |
| الحيّة | `dl/releases.json` على الخادم | `publish_release.sh` |
| المخبوزة | `site/data/releases.json` | يدويًّا بعد النشر |

رفعُ بناءٍ جديد لا يستلزم إعادةَ بناء الموقع: الصفحةُ تجلب الحيَّ عند فتحها. والمخبوزةُ
تُبقيها صادقةً إن حُجب الجلب (بلا شبكة أو حاجبِ سكربتات) بدل جدولٍ فارغٍ بلا تفسير.
و`version: null` ⇒ حالةُ فراغٍ صريحة تحيل إلى البناء من المصدر — لا نَعِد بملفٍّ لا وجودَ له.

## لماذا مولِّدٌ لنا لا قالبٌ جاهز

دعمُ RTL في القوالب الجاهزة (Docsy · Just-the-Docs · Docusaurus) طبقةُ `[dir=rtl]`
مضافةٌ لاحقًا: تغطّي التخطيطَ ولا تغطّي الحالاتِ الحدّيّة — عزلَ bidi حول `Ctrl+Shift+P`،
واتّجاهَ انزلاق الدرج، وتخطيطَ الطباعة على عمودين. وهذه بالضبط الحالاتُ التي بُني
الموقعُ لأجلها. وترقيعُها أطولُ من كتابة ما نملك، وتفرض هويّةً بصريّة تناقض هويّة محراب.

## البناء

```bash
python site/build.py            # → site/public/
python site/build.py --check    # تحقّقٌ بلا كتابة
```

المخرَجُ في `.gitignore`: يُبنى في CI عند كلّ نشر.

## البنية

| المسار | ما فيه |
| --- | --- |
| `content/*.md` | الصفحاتُ المترجَمة، لكلٍّ ترويسةُ front-matter |
| `data/site.json` | نصُّ الصفحة الأولى + مصفوفةُ المنصّات + المتطلّبات |
| `data/releases.json` | المانيفستُ المخبوز (احتياطُ صفحة التنزيل) |
| `data/keybindings.json` | مصدرُ صفحة الاختصارات |
| `data/glossary.json` | المسرد — مصدرُ الحقيقة للمصطلحات |
| `assets/mihrab-docs.css` | الرموزُ والأساسُ وصفحاتُ التوثيق |
| `assets/mihrab-home.css` | واجهةُ المنتج — مفصولةٌ كي لا يمسّ تعديلٌ تسويقيّ التوثيقَ |
| `assets/docs.js` | السمة، الدرج، البحث، صفحةُ الاختصارات |
| `assets/site.js` | تخمينُ النظام + جلبُ المانيفست الحيّ |
| `assets/shots/editor.png` | لقطةُ الصفحة الأولى (اختياريّة — يسقط إلى رسمٍ SVG معلَن) |
| `build.py` | المولِّد |

النصُّ التسويقيّ في `data/site.json` لا في بايثون: تغييرُ جملةٍ يجب ألّا يمرَّ بمراجعةِ كود.

## الفحص

```bash
python tests/docs/check_site.py     # يبني ثمّ يفحص البنية — يحجب النشر في CI
```

يمسك ما لا تراه العين: مِرساةً يبحث عنها `site.js` ولا يجدها فيموت السلوكُ صامتًا،
ومفتاحًا في `product.json` يشير إلى صفحةٍ لا تُبنى، ورابطَ تنقّلٍ مطلقًا يكسر المرآة.

## الترويسة الإلزاميّة لكلّ صفحة

```yaml
---
description: سطرٌ واحد للفهرسة والبحث.
source_path: docs/editing/codebasics.md    # صفحةُ المنبع (شرطُ النِسبة في CC BY)
translated_at: 2026-08-01
source_sha: "…"                            # بصمةُ ملفّ المنبع وقتَ الترجمة
---
```

`source_sha` تُملأ آليًّا:

```bash
python tests/docs/check_drift.py --seed     # يبذر البصمةَ للصفحات الخالية منها
python tests/docs/check_drift.py            # يقارن بالمنبع ويرفع رايةَ الانجراف
python tests/docs/check_drift.py --offline  # اكتمالُ البيانات فقط، بلا شبكة
```

بلا هذا تموت الترجمةُ صامتةً: تُترجَم مرّةً، ثمّ يتغيّر المنبع، فتبقى **تكذب بثقة**
— وهي حينئذٍ أسوأُ من غيابها.

## تعليمُ Markdown المدعوم

مجموعةٌ فرعيّة مضبوطة: عناوين `##`/`###`، فقرات، قوائم، جداول، كتلُ كودٍ مسيَّجة،
كودٌ سطريّ، روابط، `**عريض**`. وما عداها يُرفَض صراحةً لا يُتجاهَل صامتًا.

وزيادةٌ واحدة خاصّة بنا — **الاختصار**:

```
{{Ctrl+Shift+P}}
```

تُصيَّر حاويةً معزولةً اتّجاهيًّا (`unicode-bidi: isolate`). لا تكتب الاختصارَ نصًّا
عاديًّا داخل جملةٍ عربيّة: خوارزميّةُ bidi تنقل علامةَ `+` أو تعيد ترتيبَ الرموز
المجاورة، فيعرض الموقعُ `Ctrl+Shift+P` خطأً.

## المصطلحات

كلُّ مصطلحٍ من `data/glossary.json`، وفحصُ L0 يمسك البدائلَ الممنوعة. السببُ أنّ
توثيقًا يقول «لوحة الأوامر» وواجهةً تقول «لوحة الأوامر السريعة» **أسوأُ من توثيقٍ
إنجليزيّ**: يُشكِّك المستخدمَ في فهمه هو.

## الخطوط

`assets/fonts/*.woff2` غيرُ مورَّدةٍ بعد. المطلوب — IBM Plex Sans Arabic (SIL OFL)
بوزنَي 400 و600، وIBM Plex Mono بوزن 400، مُقتطَعةً على العربيّة واللاتينيّة:

```
plex-arabic-400.woff2  ·  plex-arabic-600.woff2  ·  plex-mono-400.woff2
```

يولّد `build.py` كتلَ `@font-face` **للموجود فعلًا وحده**، ويطبع تحذيرًا بالباقي.
وهذا مقصود: `@font-face` يشير إلى ملفٍّ غائبٍ لا يفشل بصوت — يُطلق 404 في كلّ فتحةِ
صفحة ثمّ يسقط صامتًا إلى خطٍّ آخر، فيبدو الموقعُ سليمًا وهو يعرض خطًّا لم نصمّم عليه.
