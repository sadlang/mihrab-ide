## تبديل السمة

{{Ctrl+K Ctrl+T}} يعرض السماتِ المثبَّتة، والتنقّلُ بالأسهم يعاينها حيًّا قبل الاختيار. يأتي محراب بسمتَي هويّة — داكنةٍ وفاتحة — مضبوطتَين لتباينٍ مريحٍ مع النصّ العربيّ.

## أيقونات الملفّات

لوحةُ الأوامر ← «سمة أيقونات الملفّات». أيقوناتُ محراب تشمل امتدادَ لغة ص `.ص` — فتميّز ملفّاتِك من نظرة.

## الخطّ

خطُّ المحرّر يُضبَط في الإعدادات، وترتيبُ الأسماء هو ترتيبُ التفضيل: أوّلُ خطٍّ متوفّرٍ يفوز.

```json
{
  "editor.fontFamily": "Cascadia Mono, Consolas, monospace",
  "editor.fontSize": 14,
  "editor.lineHeight": 1.7
}
```

`lineHeight` أهمُّ ممّا يبدو مع الكود العربيّ: التشكيلُ والنقاطُ تحت السطر تحتاج فسحةً رأسيّةً أكبر من اللاتينيّة، وارتفاعُ السطر الافتراضيّ يجعل الأسطرَ تتلامس بصريًّا.

## خطٌّ للعربيّة داخل الكود

إن كان خطُّك أحاديُّ العرض لا يحمل محارفَ عربيّة، فالنظامُ يستبدلها بخطٍّ آخر — فتختلّ المحاذاة. الحلُّ أن تُتبِع خطَّك بخطٍّ عربيٍّ صريح:

```json
{
  "editor.fontFamily": "Cascadia Mono, 'Noto Sans Arabic', monospace"
}
```

## تخصيص لونٍ بعينه

لا حاجةَ إلى سمةٍ جديدة لتغيير لونٍ واحد:

```json
{
  "workbench.colorCustomizations": {
    "statusBar.background": "#1F3A44"
  },
  "editor.tokenColorCustomizations": {
    "comments": "#8CA0A6"
  }
}
```

وهذا يعمل فوق أيّ سمةٍ مختارة، ويُحفَظ في إعداداتك لا في السمة — فلا يضيع عند تحديثها.
