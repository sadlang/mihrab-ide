## نقاط التوقّف

انقر الهامشَ يسارَ رقم السطر، أو اضغط {{F9}}. النقطةُ الحمراء تعني: قِف هنا.

ونقطةُ التوقّف ليست موضعًا فقط. زرُّ اليمين عليها يفتح:

- **شرطيّة** — تقف حين يتحقّق تعبير، مثل `i > 100`.
- **بعدد مرور** — تقف في المرور العاشر لا الأوّل.
- **نقطةُ سجلّ (logpoint)** — تطبع رسالةً ولا توقف. وهذه أنفعُ ما في الباب: تستبدل `console.log` دون تعديل الملفّ ودون إعادة بناء.

## التشغيل

{{F5}} يبدأ التنقيح، و{{Ctrl+F5}} يشغّل بلا تنقيح. أوّلُ مرّةٍ يسألك عن البيئة ثمّ يكتب `.vscode/launch.json`:

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "تشغيل البرنامج",
      "program": "${workspaceFolder}/main.js"
    }
  ]
}
```

`name` يظهر في قائمة التشغيل — سمِّه بالعربيّة وبما يميّزه حين تكثر التهيئات.

## أثناء التوقّف

| ما تريد | الاختصار |
| --- | --- |
| متابعة | {{F5}} |
| تخطّي السطر | {{F10}} |
| الدخول في الدالّة | {{F11}} |
| الخروج منها | {{Shift+F11}} |
| إيقاف | {{Shift+F5}} |

التحويمُ على أيّ متغيّرٍ يعرض قيمتَه الحاليّة. ولوحةُ **المراقبة** تُبقي تعبيرًا تحت عينك عبر الخطوات كلِّها — أضِف إليها التعبيرَ المشبوه بدل أن تحوّم عليه في كلّ خطوة.

## طرفيّة التنقيح

في لوحة **طرفيّة التنقيح** تكتب أيَّ تعبيرٍ فيُقيَّم في سياق التوقّف الحاليّ: تقرأ متغيّرًا، أو تستدعي دالّةً، أو تجرّب إصلاحًا قبل كتابته.

## كومة الاستدعاء

تعرض الطريقَ الذي أوصل التنفيذَ إلى هنا. نقرُ أيّ إطارٍ فيها ينقل المحرّرَ إليه، والمتغيّراتُ تتبدّل لتعرض سياقَ ذلك الإطار — وهي أسرعُ طريقةٍ لفهم «من نادى هذا؟».
