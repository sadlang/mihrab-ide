# تجاوزات المنتج (الطبقة الثانية)

هذا المجلّد يحوي **مساهَمات البناء** منخفضة دَيْن الدمج: حقول `product.json`، والإعدادات
الافتراضيّة، وتهيئة سوق الإضافات (Open VSX). تُدمَج فوق منتج المنبع وقت البناء **دون
لمس شيفرة النواة** (تمييزها عن رُقَع [`../patches/`](../patches/) الأعلى كلفة).

## [`product.json`](product.json) — هوية محراب (م1)

يجسّد هوية محراب. خطوة (ز-2) في [`build/build.sh`](../build/build.sh) تدمجه فوق
`product.json` الخاصّ بـVSCodium قبل `prepare_vscode.sh`، ثمّ يُعيد `prepare_vscode.sh`
دمج هذا الملفّ فوق إعداداته بـ`jq -s '.[0] * .[1]'` — وحيث إنّ ملفّنا هو المُعامِل
الثاني (`.[1]`) فقيمنا هي التي تسود عند تعارض المفاتيح. حقل `_comment` يُحذف أثناء
الدمج فلا يظهر في الناتج.

| الحقل | القيمة | ملاحظة |
|------|--------|--------|
| `nameLong` | **محراب** | الأبرز: عنوان النافذة و«حول» |
| `nameShort` | **Mihrab** | لاتينيّ عمدًا — يشتقّ اسم الملفّ التنفيذيّ `Mihrab.exe` (اسم عربيّ يكسر التوافق) |
| `applicationName` | `mihrab` | أمر سطر الأوامر `mihrab` |
| `dataFolderName` | `.mihrab` | مجلّد بيانات المستخدم |
| `urlProtocol` | `mihrab` | بروتوكول `mihrab://` |
| `serverApplicationName` | `mihrab-server` | ثنائيّ الخادم البعيد |
| `tunnelApplicationName` | `mihrab-tunnel` | ثنائيّ النفق (`mihrab-tunnel.exe`) |
| `darwinBundleIdentifier` | `com.sadlang.mihrab` | معرّف حزمة macOS (لاحقًا في م4) |
| `win32*AppId` / `clsid` | معرّفات فريدة | مولَّدة، تختلف عن VSCodium (تثبيت/تسجيل مستقلّ) |

> سوق Open VSX والإعدادات الافتراضيّة تأتي في م2/م4. الأيقونات والأصول البصريّة:
> بند م1 لاحق (تحتاج فنّ علامة محراب).

## الحالة

م1 (الهوية النصّيّة) منفَّذة عبر `product.json`. الأصول البصريّة (أيقونات) لاحقًا.
