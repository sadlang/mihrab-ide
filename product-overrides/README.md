# تجاوزات المنتج (الطبقة الثانية)

هذا المجلّد يحوي **مساهَمات البناء** منخفضة دَيْن الدمج: حقول `product.json`، والإعدادات
الافتراضيّة، وتهيئة سوق الإضافات (Open VSX). تُدمَج فوق منتج المنبع وقت البناء **دون
لمس شيفرة النواة** (تمييزها عن رُقَع [`../patches/`](../patches/) الأعلى كلفة).

## ما يأتي هنا (م1 فأكثر)

- **هويّة المنتج** (م1): `nameShort`/`nameLong` = محراب، `applicationName`،
  `dataFolderName` = `.mihrab`، معرّفات win32، `urlProtocol`.
- **سوق الإضافات**: `extensionsGallery` ⇐ Open VSX (رخصة المنبع تمنع سوق مايكروسوفت).
- **الإعدادات الافتراضيّة**: تفعيل RTL، حزم سلسلة أدوات ص (م2).
